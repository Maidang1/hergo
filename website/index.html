还有几个小问题

开始之前。

阅读项目文档
需要先安装 Herdr 吗？

Hergo 使用本机运行的 Herdr，不捆绑其可执行文件。首次启动会查找已有安装，也可以引导安装或选择已有可执行文件。只想使用本地 shell 时，可直接进入纯净终端模式。

关闭 Hergo 后，任务会停止吗？

关闭 Hergo 不会停止 Herdr 服务或关闭会话。重新打开后，可以继续连接现有会话。终端已有 owner 时，Hergo 会提供诊断和重试入口，不会自动接管。

支持哪些系统？

支持 macOS 的 Apple Silicon 与 Intel，以及 Linux amd64 / arm64。Windows x64 为实验性支持。Linux 以 Ubuntu 22.04+ 为验证基线，需要 glibc、GTK 3 和图形会话。完整要求与已知限制见项目文档。

可以参与开发吗？

欢迎。Hergo 采用 MIT 许可证，源代码和构建说明都在 GitHub。你可以报告问题、分享使用体验，也可以提交代码。 查看源代码 ↗
